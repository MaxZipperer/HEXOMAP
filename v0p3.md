# HEXOMAP Version 0.3

## Summary
HEXOMAP python and cuda codes have been updated to function on python 3.13+ and cuda 12+/13+. Many functions contained were dependent on deprecated CUDA APIs and were removed or changed. Core functionality remains the same.

## Major Changes
Recommened environment now python 3.13+ and cuda 12.x/13.x
Conda environment file added for easier environment creation
Environment file now installs cuda locally to avoid global installation requirements
Legacy cuda texture references removed
Legacy python files removed
Kernels no longer use tex2D or tex3D, instead they read directly from device memory pointers
Several kernel functions that relied on bound textures are now unbound
H5 configuration files importing strings as bytes has been resolved
Reliance on surface_functions.h removed since cuda 12 removed this header

## Minor Changes
Fixes to Frame class since python 3.14 enforces additional rules against mutable np.ndarray
Minor grammar changes
